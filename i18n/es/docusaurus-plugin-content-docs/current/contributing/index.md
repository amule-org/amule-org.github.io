aMule es un proyecto impulsado por la comunidad, mantenido por voluntarios. No necesitas ser programador para ayudar: reportar errores, traducir, mejorar la documentación, probar nuevas versiones y responder preguntas de otros usuarios son todas contribuciones valiosas.

## Dónde vive el proyecto

El desarrollo de Amule y toda su comunidad se lleva a cabo de forma pública en GitHub. Todo, el código fuente, esta web, la documentación, los reportes de errores, las peticiones de nuevas funcionalidades y las discusiones se gestionan en dos repositorios:

- **Código fuente** — [`github.com/amule-org/amule`](https://github.com/amule-org/amule): la aplicación aMule (`amule`, `amuled`, `amulegui`, `amuleweb`, `amulecmd` y las utilidades), junto con el sistema de seguimiento de incidencias y las discusiones.
- **Página Web & documentación** — [`github.com/amule-org/amule-org.github.io`](https://github.com/amule-org/amule-org.github.io): esta web y toda la documentación que estás leyendo ahora.

Si quieres seguir lo que está pasando, hacer una pregunta, o involucrarte, estos dos repositorios son el lugar adecuado.

## Cómo contribuir

### Reporte de errores

¿Has encontrado un error o algo no funciona como debería? Reportarlo es una de las mejores formas de ayudar al proyecto y no requiere conocimientos de programación. Abre una incidencia en el [sistema de seguimiento de incidencias de GitHub](https://github.com/amule-org/amule/issues). Consulta la página [Reporte de errores](bug-report.md) para saber qué información incluir y cómo generar unas trazas útiles en caso de que la aplicación falle.


### Código

Si escribes código, envía una pull request en [GitHub](https://github.com/amule-org/amule). Sigue la [guía de estilo de código](../developer/code-style.md) y asegúrate de que el proyecto compile (ver [Compilación](../developer/compilation/index.md)) — cada pull request se compila y prueba automáticamente en Windows, macOS y Linux.


### Traducciones

Amule puede ser  traducido en tres áreas: La interfaz de usuario de la aplicación, la documentación de las páginas del manual y esta página web de documentación. La [`guía de traducción`](../developer/translations.md) es el punto de partida para todas ellas, úsala para actualizar un idioma existente, añadir uno nuevo, traducir las páginas del manual o traducir esta documentación.

### Documentación

Escribir o mejorar la documentación en inglés de esta página web (su fuente está en el [repositorio de la web](https://github.com/amule-org/amule-org.github.io)). Lee la [`Guía de documentación`](../developer/documentation.md) para conocer la estructura del repositorio, las directrices de redacción y el flujo de trabajo de las pull requests. Para traducir la documentación a otro idioma, consulta [`Traducciones`](../developer/translations.md).


## Ayudar a otros usuarios

No es necesario escribir ni una sola línea de código para ayudar al proyecto. Ayudar a otras personas a usar aMule es, en sí mismo, una contribución valiosa.

Visita [GitHub Discussions](https://github.com/amule-org/amule/discussions) — el foro de la comunidad del proyecto — para responder preguntas, compartir tus consejos de configuración y ayudar a los recién llegados. Cada pregunta respondida hace que aMule sea más fácil de usar para la siguiente persona. También puedes pasarte por el canal `#aMule` en [`irc.libera.chat`](https://web.libera.chat/#aMule) para charlar en tiempo real, aunque la mayor parte de la actividad se desarrolla ahora en GitHub.
