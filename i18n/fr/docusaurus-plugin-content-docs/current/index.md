aMule est un client de partage de fichiers pair à pair libre, gratuit et multi-plateforme pour les réseaux **eD2k (eDonkey2000)** et **Kademlia (Kad)**. Il est écrit en C++ en utilisant wxWidgets et fonctionne sous GNU/Linux, FreeBSD, OpenBSD, macOS et Windows.

À l'origine dérivé d'xMule (lui-même dérivé de lMule et d'eMule), aMule est maintenu activement depuis 2003.

## Binaires

| Binaire | Description |
|---|---|
| `amule` | Client graphique tout-en-un |
| `amuled` | Démon headless (pas d'interface graphique) |
| `amulegui` | Interface graphique distante, se connecte à `amuled` via le protocole EC |
| `amuleweb` | Interface web HTTP pour exécuter `amuled` |
| `amulecmd` | Interface interactive en ligne de commande pour exécuter `amuled` |
