Le réseau ED2K (eDonkey2000) est un réseau pair à pair fondé sur les serveurs. Les clients se connectent à un serveur central pour rechercher des fichiers et trouver d'autres clients qui les partagent, mais les transferts de fichiers ont lieu directement entre les pairs.
